About

This static site, single-page application is built with:

Angular
  • Powering the portfolio with Angular's modular, component-based architecture.
  • Creating an interactive and dynamic user experience for seamless navigation.
TypeScript
  • Enhancing code readability and maintainability with TypeScript's static typing.
  • Leveraging TypeScript's object-oriented features for robust and reliable code.
Bootstrap and CSS
  • Crafting responsive, visually appealing designs with Bootstrap.
  • Using CSS to customize layouts, styling, and visual presentation.
Git and GitHub
  • Employing Git for version control to track changes efficiently.
  • Utilizing GitHub for collaboration, remote repository management, seamless deployment, and hosting the portfolio using GitHub Pages for easy accessibility.
Note: GitHub Pages and Angular Routing

GitHub Pages is a static hosting service. When a visitor opens or refreshes a nested Angular route directly, the server may return a 404 error because it cannot find a matching file or directory.

Reference: Angular Deployment Guide
